# personal-website

Source for Nick Hemauer's personal website: a single static page (HTML, CSS and JS, no build step) with education, research, work experience, and links to the resume, LinkedIn, GitHub and Google Scholar.

## Preview locally

```sh
python3 -m http.server 8090
```

Then open http://localhost:8090.

## Updating the resume

Replace `assets/Nick_Hemauer_Resume_Public.pdf`, keeping the same filename so the links on the page keep working.
